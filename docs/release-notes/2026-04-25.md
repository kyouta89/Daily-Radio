# Daily Radio アップデート（2026-04-25）

毎日のラジオ生成パイプラインを大幅に改善しました。明日から新しい仕組みで配信されます。

## 改善1：同じニュースが何日も続く問題を解消

これまで、ServiceNow関連の記事が9日連続で同じものが選ばれたり、ダイヤモンド半導体の話題が7回登場したり、「昨日も聞いた話だな」と感じることがありました。

今後は、過去14日間に紹介した記事を自動で除外する仕組みを導入。毎日新しいトピックが届きます。

## 改善2：取り上げるニュースの幅が広がりました

5つの軸（テーマ）を見直し、ニュースの源を強化しました。

| 軸 | これまで | これから |
|---|---|---|
| 軸2 | ServiceNow中心 | エンタープライズAI / SaaS全般（AWS、Microsoft、Salesforceなどが追加） |
| 軸4 | 日本の経済紙のみ | 海外の戦略系メディア（HBR、Stratechery）も追加 |
| 軸5 | スタートアップ全般 | プロダクト開発・サービスデザインの実践知に特化 |

ServiceNow関連のニュースは、新着があれば優先的に取り上げる仕組みは維持しています。

## 改善3：オープニングの「今日は何の日」が正確になりました

これまではAIが記憶を頼りに歴史ネタを生成していたため、たまに事実誤認が混ざっていました。

今後はWikipediaから当日の出来事を実際に取得して、その中からITやテクノロジー関連のものを選ぶ方式に変更。**実在する事実**だけを話します。

## 改善4：原稿の品質ノイズを除去

「私〇〇です」「（オープニングSEと共に）」のような、台本のテンプレートが本文に残ってしまうことがありました。

これらが混入しないよう、生成ルールを厳格化しました。

## 改善5（裏側）：同じ日に複数ページができる問題を解消

過去には同じ日付のページが3つ作られてしまうこともありました。今後は1日1ページに統一されます（手動で再生成したい時は明示的に指示できます）。
