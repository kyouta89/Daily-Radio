## ① Anthropic APIキー（最難関・一番先にやる）

台本を書くAIのキーです。**クレジットカードの登録と前払いクレジットの購入が必須**で、無料では使えません。経費申請が必要な場合は承認待ちで日数がかかるので、ここだけは今日明日中に着手してください。

1. [console.anthropic.com](https://console.anthropic.com) でアカウントを作る
2. 左メニューの **Billing** を開き、クレジットカードを登録する
3. 同じ画面で**クレジットを購入**する。最低 $5 からで、まずは $5 で十分
4. 左メニューの **API Keys** を開き、**Create Key** をクリック
5. 表示されたキー（`sk-ant-` で始まる長い文字列）を**その場でコピーして保存**する

⚠️ **キーは作成直後の1回しか表示されません。** 画面を閉じると二度と見られないので、必ずコピーしてメモ帳などに貼っておいてください。忘れた場合は作り直しになります（作り直し自体は無料です）。

費用の目安は「毎日1本配信して月 $3〜5 程度」です。残高が尽きるとその日から番組が作られなくなるので、月に一度 Billing 画面を見る習慣にしておくと安心です。

## ② Gemini APIキー と ③ Notion

### ② Gemini APIキー（課金が必要・20分）

声を作るAIのキーです。**Google Cloud の請求先アカウント（クレジットカード）の登録が必要**です。番組が使う音声合成モデルは、課金を有効にした状態（Tier 1）で回る前提になっています。

1. [aistudio.google.com](https://aistudio.google.com) に Google アカウントでログイン
2. **Get API key** → **Create API key** をクリック
3. キーを作るときに **Google Cloud プロジェクト**を選ぶ（無ければその場で作れます）
4. [console.cloud.google.com/billing](https://console.cloud.google.com/billing) を開き、**そのプロジェクトに請求先アカウント（クレジットカード）を紐づける**
5. 表示されたキー（`AIza` で始まる文字列）をコピーして保存

料金は作った音声の長さに対してかかり、**1本あたり約 $0.3、月 $6〜7 程度**です。課金を有効にすると1日100回・1分あたり10回まで使えます。番組1本で使うのは7回前後なので、上限には余裕があります。**このキーは他の人と共有せず、必ず自分で取ってください**（共有すると上限と請求を互いに食い合います）。

### ③ Notion（無料・30分）

「昨日と同じ記事を選ばない」ための記録と、台本の保管場所に使います。番組の動作に必須です。

1. [notion.so](https://notion.so) でアカウントを作る
2. 新しいページで「データベース（フルページ）」を作る。名前は「ラジオ原稿」など何でもOK
3. プロパティ（列）を3つ用意する。**この綴りのまま**作ってください
    - `Name`（タイトル。最初からあるのでそのまま）
    - `Date`（日付）
    - `Tags`（マルチセレクト）
4. [notion.so/my-integrations](https://notion.so/my-integrations) で **New integration** を作り、**Internal Integration Secret**（`ntn_` で始まる）をコピーして保存
5. 作ったデータベースのページで右上の **・・・** → **接続**（Connections）→ いま作ったインテグレーションを追加
6. データベースのURLから**データベースID**を控える。`notion.so/ここの32桁?v=...` の、`?` の手前にある32桁の英数字

⚠️ **手順5の「接続」を忘れるのが一番多い失敗です。** これをしないと、キーが正しくてもプログラムからデータベースが完全に見えず、当日エラーになります。

## ④ Cloudflare R2（音声の置き場所・40分）

作った音声ファイルを置いて、ポッドキャストアプリから取りに来てもらう場所です。**ここだけで 5 つのキーが取れます**ので、メモを取りながら進めてください。無料枠の範囲で収まりますが、**R2 の有効化には支払い方法の登録が必要**です。

1. [dash.cloudflare.com](https://dash.cloudflare.com) でアカウントを作る
2. 左メニューの **R2** を開く。初回は支払い方法の登録を求められるので登録する
3. **Create bucket** で入れ物を作る。名前は半角英数字（例: `my-radio`）→ この名前が **キー② バケット名**
4. 作ったバケットを開き **Settings** → **Public Development URL** を有効にする。`https://pub-….r2.dev` というURLが出る → これが **キー③ 公開URL**
5. R2 の画面に戻り **Manage API Tokens** → **Create API Token**。権限は **Object Read & Write**、対象はいま作ったバケットを選んで作成
    - 表示される **Access Key ID** → **キー④**
    - 表示される **Secret Access Key** → **キー⑤**
6. 画面に出ている **Account ID**（32桁の英数字）を控える → **キー①**

⚠️ **Secret Access Key も 1 回しか表示されません。** 閉じる前に必ずコピーしてください。失くしたらトークンを作り直せばOKです。

バケットは「URLを知っている人だけが取れる」状態になります（一覧は見られません）。当日、推測できない合言葉を使って**自分しか聴けない配信**にしますので、ここでは公開のままで問題ありません。

## ⑤ カバー画像（20分）

ポッドキャストアプリで番組のアイコンになる画像です。**Apple の必須要件があり、条件を満たさないと番組を追加できないことがあります。**

| 項目 | 条件 |
| --- | --- |
| サイズ | 1400×1400 ピクセル以上（3000×3000 以下） |
| 形 | 正方形（縦横同じ） |
| 形式 | PNG |
| ファイル名 | `thumbnail.png`（この名前でないと表示されません） |

作り方は自由ですが、[Canva](https://www.canva.com) で「1400×1400 のカスタムサイズ」を作って、番組名を大きく置くだけで十分です。スマホでは小さく表示されるので、**文字は大きく、要素は少なく**がコツです。

注意点として、拾ってきた画像や会社のロゴをそのまま使わないでください。配信自体は自分しか聴かない設定にしますが、ファイルはネット上に置かれます。

作った画像は **`thumbnail.png` というファイル名で保存して、パソコンに置いておくだけ**でOKです。R2 へのアップロードは当日一緒にやります。
